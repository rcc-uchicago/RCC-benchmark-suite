# Spack Environment

Spack was used by RCC to build dependencies necessary to run this benchmark for
internal testing purposes. The `spack.yaml` and `spack.lock` files of the Spack
[environment](https://spack-tutorial.readthedocs.io/en/latest/tutorial_environments.html)
used by RCC are available here. The file `env-hpcg-nvidia.txt` contains the
output of the command `spack find -lfdvI` executed with the environment loaded.
